# ApexPlanet-Data-Analytics-Task-3
Deep-Dive Analysis and Interactive Sales Dashboard using Power BI


### Project Overview
This project focuses on deep-dive sales analysis and interactive dashboard development using Microsoft Power BI as part of the ApexPlanet Data Analytics Internship.

### Objectives
- Define and calculate key performance indicators.
- Analyze customer segments and purchasing patterns.
- Identify sales trends across cities and product categories.
- Develop an interactive sales performance dashboard.
- Support data-driven business decisions.

### Tools and Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Power BI Service
- GitHub

### Dataset Overview
- Total Records: 1,000
- Dataset: Cleaned Sales Dataset
- Attributes: Order ID, Customer ID, Age, Gender, City, Category, Quantity, Unit Price and Total Sales.

### Key Performance Indicators
1. Total Revenue
2. Total Orders
3. Unique Customers
4. Average Order Value
5. Revenue per Customer

### Deep-Dive Analysis
- Age Group-wise Revenue Analysis
- Gender-wise Revenue Analysis
- City-wise Revenue Analysis
- Product Category-wise Revenue Analysis
- Monthly Revenue Trend

### Interactive Dashboard Features
- Interactive KPI cards
- Customer segmentation
- Dynamic slicers
- Cross-page synchronized filters
- Page navigation buttons
- Interactive charts and visualizations
